# Design References

A catalog of every visual reference Luneth has shown me, with descriptions of what each one represents and why it landed (or didn't). When the user attaches an image to a message, it appears in my context but isn't always saved to disk where I can copy it — so this folder is descriptions + URLs, supplemented with any image files I'm able to save.

Cross-reference with `../design-knowledge.md` for the principles each reference embodies.

---

## How to use this folder

- **Read this README first** when starting any visual work. The references here are the *whole language family* the user designs in.
- **Match the DNA, not the surface.** Each reference is shown for one or two specific qualities — capture those, don't copy the whole image.
- **Update this file** when Luneth shows a new reference. Add: source URL or file, one-paragraph description of what they liked, what category of design problem it solves.

## REFERENCE 1 — Apple Vision Pro Lifestats Dashboard

**Source:** https://dribbble.com/shots/21853047-Apple-vision-pro-LifeStats-Health-Dashboard
**Shown:** Phase 12 round-7 (theme overhaul)
**What Luneth liked:** "love this vibe" — glass / surreal / atmospheric. Frosted-glass dashboard panels floating over a dark photographic interior (a living room). The glass panels are translucent, the wallpaper shows through softly, every element feels weightless.
**What to extract:** The contrast between focused panel content + soft photographic backdrop. The panels don't fight the background; they sit calmly on it.

## REFERENCE 2 — iHealth Healthcare Tracker

**Source:** https://www.behance.net/gallery/221811245/iHealth-Healthcare-Tracker-App-Design
**Shown:** Phase 12 round-7
**What Luneth liked:** Light, healthy, blue accents, 3D heart illustration, generous whitespace. Clean medical-app energy without the sterility.
**What to extract:** How to do "light/health" without it reading sterile or generic-medical. Whitespace is doing real work here.

## REFERENCE 3 — Hynex Healthcare Dashboard

**Source:** https://me.muz.li/orbix-studio/hynex-healthcare-dashboard-design-2
**Shown:** Phase 12 round-7
**What Luneth liked:** "love the colors, dark themes with a bit of saturation/color is much better than dark themes that are totally grayscale, and it allows for more graphical choices too since hued colors allow more details (such as glass/aero effects) much better than gray colors which tend to color band"
**What to extract:** Dark mode isn't flat grayscale. Saturated emerald + teal hues, glass crystal asset as the central visual, gradient elements that read as designed.

## REFERENCE 4 — NobleFinance Smart Finance Dashboard

**Source:** https://dribbble.com/shots/26385971-Smart-Finance-Dashboard-UI-Design-NobleFinance
**Shown:** Phase 12 round-7
**What Luneth liked:** "this reminds me of the old school green mid-tone steam games program layout, such a cool/old school vibe, would be super cool to have a theme that almost FEELS like a copy of the old Steam interface, a true blast to the past vibe"
**What to extract:** Saturated lime-green on near-black, mid-tone Steam aesthetic, real graphic personality. THIS is the inspiration for any future dark-mode-with-nostalgia theme. (Also the Eclipse theme attempt was a too-cool reading of this; the user wants more saturated GREEN, less neutral teal.)

## REFERENCE 5 — Juicelab Fitness Tracking Dashboard

**Source:** https://me.muz.li/juicelab-design/fitness-tracking-dashboard-2
**Shown:** Phase 12 round-7
**What Luneth liked:** "love these see through effects that rely on an amazing background to bring it together"
**What to extract:** Dark photographic background of an athlete; translucent dashboard panels overlay. The panels are sub-100% opacity, the photograph carries the mood, dashboard rides on top.

## REFERENCE 6 — Juicelab Golf Analytics Dashboard

**Source:** https://me.muz.li/juicelab-design/golf-analytics-dashboard-ui-player-performance-2
**Shown:** Phase 12 round-7
**What Luneth liked:** Same as Reference 5 — the see-through/glass effects over a stunning photographic background. An aerial golf course shot under a green-tinted glass overlay.
**What to extract:** Photography as the design's emotional substrate. Glass-aero effects need a beautiful background to be beautiful themselves.

## REFERENCE 7 — Juicelab Real Estate Analytics Dashboard

**Source:** https://me.muz.li/juicelab-design/real-estate-analytics-dashboard-market-buyer-intelligence-2
**Shown:** Phase 12 round-7
**What Luneth liked:** Same family — warm sand/architecture background, frosted overlay, warm-orange accents.
**What to extract:** Warm-palette dashboards. Sand/architecture textures work as backgrounds for analytics surfaces. Translucent overlays in a related warm hue.

## REFERENCE 8 — Vyniq Vacuum Cleaner Dashboard

**Source:** https://me.muz.li/hasan/vyniq-vacuum-cleaner-dashboard-intuitive-web-app-2
**Shown:** Phase 12 round-7
**What Luneth liked:** "pretty cool they managed a light theme that isn't TOTALLY light, it's kinda gray and flat, but in a cool way with the orange tones, give me an almost futuristic megastructure vibe"
**What to extract:** Light theme that isn't sterile. Gray-warm base with deliberate orange accents. Reads as "designed by an architect" — restrained, planar, intentional.

## REFERENCE 9 — Pink Keyboard Keys (ESC / Up / Enter)

**Source:** Attached image, Phase 12 round-15
**What Luneth liked:** Clean monochrome pink, ESC and arrow and enter keys with restrained inset shadows. "Less is more, using negative space is GREAT, especially with subtle glows/shadows that are tasteful and sleek."
**What to extract:** The keys are not flat — they're embossed/recessed into the surrounding rounded slab. The shadow direction is consistent (light source above-left). The pink is ONE color, used throughout. Negative space carries the design.

## REFERENCE 10 — Glass Iridescent "Join now" Button

**Source:** Attached image, Phase 12 round-15
**What Luneth liked:** Translucent glass-like button with pink/orange/purple iridescent smudges, soft outer aura on the background showing the iridescence. Black text inside.
**What to extract:** This is a HIGH-EMPHASIS specialty button — premium CTA energy. NOT for navigation; for "this is the most important action on the page." Iridescence + glass treatment together signal "premium / specialty / pay attention."

## REFERENCE 11 — Twitter Circles (Debossed)

**Source:** Attached image, Phase 12 round-15
**What Luneth liked:** Pure neumorphism. Three white circles on a near-white background. The Twitter bird logo is INSET into each circle (debossed, not embossed). Different levels of inset depth across the three.
**What to extract:** Neumorphism done right. Monochrome white-on-white. Shadow + highlight work together — the inset shadow gives the logo its form, the outer surface gets no extra treatment. Restraint to the maximum.

## REFERENCE 12 — Refract Pill Button

**Source:** Attached image, Phase 12 round-15
**What Luneth liked:** Clean white pill, subtle inner gradient (very pale blue tint), neumorphic shadow (subtle outer drop + inner top highlight), dark blue serif text "Refract" in the center. On a dotted-grid background.
**What to extract:** **THIS is the closest reference for the dashboard's nav-scale feature buttons.** Pill shape, near-white body with the slightest tint, soft shadow, the color identity is in the TEXT not the body, no glossy highlight band, no saturated gradient. The button looks SCULPTED, not painted.

## REFERENCE 13 — HTML/CSS 3D Button Guide

**Source:** https://blog.replaybird.com/html-and-css-3d-button-guide/
**Shown:** Phase 12 round-15
**What Luneth shared:** The literal guide for what neumorphic 3D buttons should look and behave like.
**What to extract:** Technical reference for the neumorphic button approach. The shadow recipes there ARE the recipes to use.
