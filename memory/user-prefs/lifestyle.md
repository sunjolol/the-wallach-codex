# Lifestyle & Format — User Preferences

_Cross-cutting. Applies to all body-system recommendations: format, cost, sustainability, hard nos, trusted brands._  
_See [index](index.md) for the file map. Related: [`communication.md`](communication.md), every body-system file inherits from this unless it specifies an override._

## Format preferences (supplement form)

- **Capsules are ideal.** Default preference for any new product.
- **Powders are acceptable** as needed for products that genuinely require powder format (e.g., Beyond Osteo FX, Majestic Earth PDM Liquid). User's words: *"I'd almost prefer powders as a catch up system or something."*
- **Liquids acceptable** for products like Majestic Earth PDM where the form is integral to absorption mechanism (Wallach's "plant derived colloidal" framework).
- **NO powder-mixing as daily routine** — user has fatigue-tolerance limit for daily powder protocols. Acceptable for occasional/catch-up use; not for every-meal protocols.

## Lifestyle / cost discipline

- **Cost-sensitive but not extreme.** "Not crazy costs" was the explicit framing. The ~$80–120/month additional discussed appears to be in acceptable range; explicit confirmation pending.
- **Lifestyle sustainability > maximum supplementation.** User's words: *"effortless to maintain rather than what I'm doing now which is sort of covering some basics."* Recommendations that require major behavior change should be flagged as such, not buried as if they're trivial.
- **Convenience prioritized.** Implies: don't recommend products that require special timing, food restrictions, or refrigeration unless mechanism really demands it.

## Hard nos (so far)

- **Cooking eggs** — strong dislike. Pre-boiled + peeled is the sustainable form.
- **Organ meat directly** — cannot stomach. Capsule bridge acceptable.
- **Daily powder-mixing as routine** — fatigue-tolerance limit (also under Format above; cross-listed because it functions as both a format pref AND a hard-no for "every meal" cadence).

## Soft preferences (dietary)

- Pre-prepared / no-cook proteins (pre-boiled eggs, smoked salmon, store-bought chicken strips) for sustainability.

## Trusted brands

- **Youngevity** — corpus-aligned (Wallach's company; primary product source per source-rule cornerstone).
- **Mercola** — for iodine specifically; needs replacement (Wallach-friendly equivalent).
- **Siggi's** (Skyr) — switching to whole-milk version.
- **HIPPEAS** — clean chips for indulgence.

New brand preferences accumulate here as they emerge. When a brand preference becomes body-system-specific (e.g., a strength-specific brand the user trusts more than the cross-cutting list), promote it to the relevant body-system file with a back-link.
