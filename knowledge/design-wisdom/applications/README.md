## Format

Each entry timestamps the application + cross-links the reference + describes the adaptation. Honest about what was kept verbatim vs adapted vs abandoned.

```
## (YYYY-MM-DD at H:MM AM/PM) — Feature / surface name

**References used:** #NNN, #NNN, ...
**Project:** Which project, which file, which surface
**Kept verbatim:** Which CSS/HTML patterns made it through unchanged
**Adapted:** What was modified and why
**Abandoned:** What we tried from the reference and dropped, and why
**Result:** Outcome (user approved / iterated further / replaced entirely)
```
