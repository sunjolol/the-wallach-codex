# Fringe-knowledge — contained Wallach claims held OUT of the app + Eden

_A clean containment zone for Wallach claims deliberately kept OUT of the sealed
corpus (`eden/corpus/`) and OUT of every app surface (Coverage / Knowledge /
Conditions). Recorded faithfully + in full for Luneth's later MANUAL review — to
decide, category by category, if/what ever earns a place in Eden. **Never
front-facing.**_

## Why this exists
§00.A keeps Wallach as the cornerstone, so excluded content is never deleted — it
stays faithful to Wallach and is preserved here. But not every Wallach statement
belongs in a nutrient-coverage product: some is fringe, unfalsifiable,
reputationally risky, dated, or simply off-mission. Those are contained here,
organized by category, so the corpus stays clean while the full picture remains
knowable in one place.

## The policy (agreed 2026-06-24)
1. **Exclusion is EXTREME-cases only.** Default is to extract faithfully;
   exclusion is the rare exception.
2. **Luneth rules EVERY exclusion — every time.** The agent never excludes
   silently. Each candidate is surfaced for his call and recorded here.
3. **Excluded != deleted.** Summary + Wallach's verbatim + locator are preserved
   so the complete picture survives for study. It simply does not enter
   `eden/corpus/` or any app surface.
4. **Format mirrors the corpus:** a plain-language summary, then Wallach's own
   words (verbatim) + book/page locator.
5. **One file per category.** Each fringe theme is its own containment file in
   this folder, so later review is per-category and what (if anything) graduates
   to Eden is a clean, manual decision.

## Categories
- `criminal-behavior.md` — minerals / deficiency linked to violent, criminal, or antisocial behavior.
- `social-emotional-defects.md` — the "emotional defects" framing (incl. dated social claims).

_Locators are page/chapter-based (durable across re-OCR). Appended to, never pruned._
