# ★ LESSONS THAT WILL COST A SESSION IF LOST

1. **MULTIPLE DEMOS ALWAYS** — build wide, then let him pick. Never narrow first.
2. **`markerUnits` defaults to `strokeWidth`.** A 7-unit arrowhead on a 12px stroke renders at
   ~84px and can bury a label. Use `userSpaceOnUse` — then check the head is not painted *behind*
   a later opaque shape.
3. **Never eyeball a Bézier control point.** A guessed one produced an "extension" that cut inside
   its own curve. Split the real curve with de Casteljau.
4. **An infinite animation loop can make a figure's own claim false** for part of every cycle.
   For anything asserting a quantity, one-shot with `fill-mode: both` — the settled state is the
   only true state.
5. **A borrowed component is adapted by OMITTING, never by editing its CSS.** The Astoria board card
   silently clips its description; the fix is shorter copy. Sweep *every* instance — the sweep found
   a pre-existing clipped card nobody had noticed.
6. **The measure step and eyes catch different things.** `mockup_measure` passed all seven while
   five real defects sat in the pixels. It says so itself: text-vs-text only.
7. **The harness `--panel` splits on the FIRST colon**, so a Windows path (`C:/…`) is fine but an
   MSYS path (`/c/…`) silently yields an empty panel — the shell built at 6 KB instead of 84 KB.
