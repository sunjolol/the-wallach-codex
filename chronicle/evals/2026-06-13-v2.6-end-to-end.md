## Cross-tool integration

The tool surface composes correctly:
- A symptom → `symptom_lookup` → named deficiency → `catalog_index --nutrient` → ranked products → `conflict_detector` to validate stack additions → `lab_interpreter` to verify deficiency biomarker if user has labs.
- A lab → `lab_interpreter` → first-action protocol → `catalog_index --product` to confirm doses → `conflict_detector` to check interactions.
- A goal → `catalog_index --goal` → WHY-layer markdown for mechanism → `corpus_search` for direct quotes.
