# Decision: the public domain is `nutrientcodex.com` — Wallach's name stays off it

_2026-08-20. Luneth's ruling, made against a shortlist verified available at the time._

★ **STATUS: PURCHASED.** He registered it the same evening, and already holds SiteGround hosting.
The name is settled; do not re-open it. Hosting mechanics are a separate matter and the charter
question at the foot of this file is still unanswered.

## The ruling
**`nutrientcodex.com`.** Keyword in front, brand behind, 13 characters — the same length as the
`wallachcodex.com` he started from, so dropping his name cost nothing.

## Why Wallach's name comes off
His own two reasons: the name would have to change if Wallach ever objected to it, and it sends the
wrong impression that Wallach built this.

**The third reason, which is the load-bearing one:** this app already contradicts him on his own
terms and must stay free to. Silver's 400 mcg was ruled a ceiling and not a target; tin was ruled
vehicle-supplied; the germanium gap is stated as a gap rather than papered over. A name that reads
as *his* makes every one of those corrections look like a betrayal instead of scholarship. §00.A
makes him the only source of amounts — it does not make him the proprietor of the reading.

## ★ The measured finding that killed the whole "90" family
The framework's signature number was the obvious brand. It is not available in any spelling that
matters, and the occupants are the wrong neighbours:

| domain | what is actually served there |
|---|---|
| `90minerals.com` | **a live Youngevity products site** |
| `90essentials.com` | "90 Essentials Group" + a sales phone number |
| `essential90.com` | parked, listed for sale on HugeDomains |
| `90nutrients.com` | registered, responds, no title |
| `the90.com` | unrelated — a gem/jewellery brand |
| `cover90.com` | registered |

So every numeral spelling is taken, mostly by Youngevity sellers. Branding on the number would leak
type-in traffic to them and — the real cost — make the Codex look like the one thing it is not: a
Youngevity storefront. Youngevity is **composition only, never a target** here, and the app already
recommends brand-agnostic single-ingredient supplements where Youngevity cannot reach. The name must
not undo that in the address bar.

**Consequence:** `ninetyessentials.com`, `ninetynutrients.com`, `ninetyminerals.com`,
`the90essentials.com`, `the90codex.com`, `90codex.com`, `covermy90.com`, `90check.com`,
`covered90.com` were all confirmed AVAILABLE and were all rejected anyway. Availability was never
the problem. Do not re-propose them.

## Method — how availability was established
Registration status came from **RDAP, not a registrar search box**: `rdap.verisign.com` for
`.com`/`.net` (HTTP 404 = unregistered, 200 = registered), `rdap.org` for other TLDs. Controls ran
first — `GOOGLE.COM` returned 200 and a nonsense string returned 404 — so the instrument was shown
to distinguish the two states before any candidate was trusted. Finalists were then cross-checked
for nameservers; a registered domain almost always has NS records, and every finalist had none.

⚠ Availability is point-in-time. Any name in the runner-up list below may be gone. Re-check with the
same method before acting on it — never quote this file as current.

## The SEO claim, stated honestly
A descriptive domain was wanted for search advantage. The honest position: **an exact-match domain
is a weak ranking signal** — Google devalued it in the 2012 EMD update. The real return on a
descriptive name is that a human reading the result understands it and clicks. The name was chosen
on that basis, not on a promise about rankings.

## ⚠ What this does NOT settle
Choosing a domain is not the charter ruling. `CLAUDE.md` still opens with *"Opens from `file://`.
No server, no backend, no accounts, no telemetry, no network at runtime … it cannot be taken offline
or broken by an update."* A statically-hosted build keeps no-backend, no-accounts and no-telemetry
intact, but **"no network at runtime" and "cannot be taken offline" stop being literally true**
unless the downloadable build remains the primary artifact and the hosted build is explicitly a
second distribution. That is a §00.B charter change and it is still open. Do not treat a purchased
domain as consent to it.
