# Header-research dossiers — design head-starts for the remaining element headers

_Created 2026-08-01 (autonomous research pass, while Luneth is away). Purpose: front-load the
LOW-RISK, high-usage conceptual research so that when we DESIGN each element header next week, the
concepts, their grounding, and the reasons they were chosen are already decided and never re-derived._

## What each dossier is (and is NOT)
Each `<slug>.md` is the research blueprint for ONE element's header — the block between "At a glance"
and "Worth knowing", built bespoke like the 6 shipped headers (selenium · copper · zinc · calcium ·
magnesium · vitamin A). A dossier contains: (1) story material — the element's sealed Wallach claims
grouped by angle, each with its claim ID; (2) 4 genuinely distinct header concepts (per Rule 0 of
`.claude/rules/element-headers.md` — NOT the selenium chassis), each anchored to exact claim IDs +
numbers; (3) WHY each concept wows (impact / UX rationale); (4) proposed `lede` + "why this number"
(PROPOSALS — Luneth ratifies one at a time); (5) gap flags.

**A dossier is NOT a design.** It stops before layout/copy execution. Next week: read the dossier →
build 4 mockups fast → Luneth picks → build → STOP for his visual sign-off (the normal workflow).

## The hard rule (why this is low-risk)
**Every concept traces to a sealed claim ID, or it is flagged as a GAP. No invention, no outside
knowledge, no web.** Each agent saw ONLY a deterministic claim-pack for its element (extracted from
the sealed corpus), so it could not roam or drift. A grounding validator confirms every cited claim
ID is real AND in that element's pack (0 hallucinated IDs across the pass). This rests on Wallach's
own words (§00.A), so it will not need revamping.

## Selection
**Impact × richness**, viable bespoke set: the 29 remaining "name-brand" essentials with ≥~10 sealed
Wallach claims. Deferred to a separate "group vs solo" decision (NOT researched here): the thin amino
acids, other thin minerals, the H/C/N/O backbone, and the 35 rare-earth trace minerals (a group
concept, not individual headers).
